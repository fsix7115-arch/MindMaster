FAQ

Why is it not on the Play Store?

It is sideloaded for now. Store release needs a release keystore, a privacy policy URL, and a signed build — all in progress. The APK you download right now works, it just isn't signed for store distribution.

Is there a Windows version?

Not yet. A Windows build needs a Windows toolchain, so it will come from a Windows CI runner. The button on this page is deliberately disabled rather than linking to nothing.

Does it need internet?

No. There is no account, no server and no analytics. Airplane mode is fine.

Why only two games?

Because shipping two finished games beats describing six half-built ones. The remaining four are on the roadmap and are shown as unfinished in the app itself.

Can I contribute?

Yes — github.com/fsix7115-arch/MindMaster. The game rules are deliberately kept in pure Dart so they are easy to test and to change.
